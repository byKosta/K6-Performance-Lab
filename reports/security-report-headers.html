[Security] Два отсутствующих HTTP заголовка на test-api.itemit.com

Найдено в ходе автоматического k6 security тестирования · 2026-08-10

Привет! Во время performance/security тестирования нашёл пару вещей в конфигурации сервера. Не баги в коде — настройки на уровне nginx/CDN.

#1

Отсутствует Strict-Transport-Security (HSTS)

🔶 Medium
Что: Сервер не отправляет заголовок, указывающий браузерам использовать только HTTPS.
Риск: В незащищённых сетях (public WiFi) возможна MITM-атака с перехватом x-user-token и x-api-key.
Проверить:
# Заголовок отсутствует в ответе:
curl -I https://test-api.itemit.com/v1/account \
  -H "x-api-key: <your-key>"

# Strict-Transport-Security: — не будет в выводе
Фикс:
# nginx.conf
add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
#2

Отсутствует X-Content-Type-Options: nosniff

🔶 Medium
Что: Сервер не запрещает браузерам угадывать MIME-тип ответа.
Риск: Потенциальный XSS через загрузку файлов (эндпоинт PUT /files/{id}/content) — браузер может выполнить загруженный файл как JavaScript.
Проверить:
# Заголовок отсутствует в ответе:
curl -I "https://test-api.itemit.com/v1/item-profiles?limit=1" \
  -H "x-api-key: <your-key>"

# X-Content-Type-Options: — не будет в выводе
Фикс:
# nginx.conf
add_header X-Content-Type-Options "nosniff" always;
